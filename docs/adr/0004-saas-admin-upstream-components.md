# SaaS 后台直接复用 shadcn/ui Base UI 组件

2026-10-08 用户确认：SaaS 后台模板统一采用 shadcn/ui 的 Base UI 版本，以免费 AdminCN（dd1afd2f3a794ea9e746197de314f81d43670ea1）为源码和视觉基线，接受其 Orders 总览与原 Sales 演示的内容差异；允许官方配套库及其间接依赖，不要求依赖树完全没有 Radix，不自行换用 Radix 版控件。正常 props、className、主题配置和页面组合可以进行，修改组件源码、API、默认交互或新增自定义组件须提前说明并确认；这项决定优先于该模板此前的自有组件复用方向，避免再次以自写控件重组近似后台。现有资产、公开身份和其他模板不随此决定自动迁移，来源许可保留，安装兼容性、来源符合性、工程验证与用户视觉确认分别记录。

用户随后明确要求删除旧版本，旧 ProjectWorkspaceSite 及其专属源码和安装身份移除，覆盖此前保留旧版本的建议；其他共享资产及独立主题继续保留。首批页面范围与上游默认 + Blue Ink 主题方案已确认，完整验收规格与具体适配差异继续核对；方向确认不等于视觉通过，也不授权未知组件改动。

后续用户“可以”确认完整规格及具体适配包，最新“可以”确认两个源码差异：Free Timeline 与 BackgroundRipple 原样作为模板私有区块保留；官方 use-mobile 仅改新建 helper 的阈值到1280，保留官方 SSR 初始化及 Sidebar/Sheet源码。来源、普通调用方适配、许可缺口及实测范围记录在 docs/sources/saas-admin.md 与计划011。
