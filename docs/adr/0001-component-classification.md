# 组件按职责分，不按体积分

组件和区块曾经按「动效基础件」和「用基础件拼成的复合件」划分，也考虑过按体积分成大组件和小组件。两种分法都会把侧栏这类单一零件划进区块，或把已经存在的动效组件划出组件。

决定采用单一职责、可组合、可分发。一个名字、一个安装入口、一件界面上的事，就是组件。体积无关。一段已经排好、一次安装带走其中组件的布局，才是区块。定义时的名字、接口和源码，就是引入后得到的那一份。

页面是一屏，整站是多屏，都留在本仓库。整站只登记页面名字。新控件优先用 shadcn/ui。现有 `components/motion` 与 `components/agents` 先不因这条决定搬迁。
