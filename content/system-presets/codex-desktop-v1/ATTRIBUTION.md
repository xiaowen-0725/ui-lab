# Attribution and rights boundary

本 reference pack 不构成官方指南，也不授予字体、源码或品牌资产的许可。当前截图都是 calibration evidence，不能被称为同尺寸 acceptance golden。`codex-desktop-light` 是 private screenshot evidence：仓库只保存其尺寸、哈希和 provenance，不发布图片 bytes；Phase 2 golden captures 仅在用户 checkout 后按确定性 fixture 生成。
