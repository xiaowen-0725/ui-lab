# Attribution and rights boundary

两张 vendored 截图是用户授权的视觉参考。OpenAI、Codex 名称、商标、截图和任何专有资产的权利均归各自权利人所有。

本 reference pack 不构成官方指南，也不授予字体、源码或品牌资产的许可。真实外部截图都是 calibration source，不能被称为同尺寸 acceptance capture。`codex-desktop-light` 是 private screenshot evidence：仓库只保存其尺寸、哈希和 provenance，不发布图片 bytes。Phase 2 按确定性 fixture 自生成的截图属于 candidate regression capture，只能防回归；只有用户明确批准后才成为 approved acceptance capture，并且只有 approved acceptance 才能解锁 checkout 与 Confirmed Manifest。
